## 9. Data model (MongoDB)

- `users`: `firebase_uid` (unique), `email`, `name`, `created_at`
- `resumes`: `user_id`, `profile` {name, headline, skills[], projects[{name, summary, tech[]}], experience[], education[], years_experience}, `created_at` (no raw text, no file)
- `interviews`: state fields listed in `engine.md` section 7.2, `user_id`, `resume_id`, `created_at`, `updated_at`
- `reports`: `interview_id`, `user_id`, overall score, dimension averages, communication metrics, camera metrics, narrative, per-question list, `created_at`

Indexes: `users.firebase_uid` unique; `interviews.user_id + created_at`; `reports.user_id + created_at`. Every query filters by the current `user_id`. A user must never read another user's data (test it).

GROQ_MODEL_REPORT=

GEMINI_MODEL_REPORT=

NVIDIA_MODEL=

TIME_LIMIT_MINUTES_DEFAULT=25
CORS_ORIGINS=http://localhost:5173

Frontend `.env.example`: the four `VITE_FIREBASE_*` values. API calls go through the Vite proxy.
